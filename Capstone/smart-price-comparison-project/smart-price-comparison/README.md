# Smart E-Commerce Price Comparison and Deal Alert Platform

## Features
- **Live Price Comparison:** Searches any product across Amazon.in and Flipkart simultaneously.
- **Lowest Price Recommendation:** Automatically highlights the cheapest platform, calculates savings, and provides a direct link to place the order on the retailer's site.
- **Price History & Deal Alerts:** Stores price snapshots in MySQL, visualizes price trends, and emails users when prices drop below their target.
